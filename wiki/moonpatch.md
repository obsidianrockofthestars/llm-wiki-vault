# Moonpatch

**Summary**: Riley's cozy 2D night-gardening game, core loop playable. Current thread: tutorial rewrite around a single immediately-paid-off mechanic; compost system cut from v1.

**Sources**: Raw/01 - Projects/moonpatch.md, Raw/03 - Session Logs/2026-01-20-0930 - First wiki build from three sources.md

**Last updated**: 2026-01-20

---

Plan the garden by day, the night phase runs itself, dawn surprises you. Built nights and weekends with AI assistance. Three playtesters (source: Raw/01 - Projects/moonpatch.md).

## The tutorial rewrite

All three playtesters got lost in the first five minutes of the explain-everything tutorial ("a lot of reading before the fun part"). Rewrite: teach ONE thing, deliver the night-growth payoff immediately, introduce each further system only when the player hits the wall that system solves.

Riley spotted, unprompted, that this is the same shape as the [[flour-hour]] loyalty decision. That observation became [[reward-adjacency]] (the timing rule) and [[onboarding-philosophy]] (the sequencing rule).

## Scope decisions

- Compost system cut from v1, per Done beats perfect (decision recorded in the 2026-01-20 session log).
- Night phase length (fixed vs skippable) still open.

## Cross-domain connections

Tutorial sequencing generalizes to any first-run experience, including how [[flour-hour]] introduces new customers to the points program: one mechanic, immediate payoff, details later. See [[onboarding-philosophy]].
